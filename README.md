# 생기부 코치 — 배포 가이드 (Google 로그인 + Firebase + Gemini API, 전부 무료)

이 버전은 이전 버전에서 이렇게 바뀌었어요.

- 아이디/비밀번호 대신 **구글 계정으로 로그인**해요 (더 안전해요).
- 접속하면 바로 로그인 화면이 아니라 **앱 소개 화면**이 먼저 뜨고, "시작하기"를 누르면 로그인으로 넘어가요. 소개 화면에는 이 앱을 만든 이유와 바라는 점을 담은 카드 2개가 보여요. 이 화면은 어떤 색상 설정을 하든 항상 흰 배경으로 고정돼요.
- **내 작품 페이지**가 생겨서, 수행평가 등 내가 만든 걸 제목과 글로 저장해둘 수 있어요. (파일 첨부 기능은 없어요 — 글로만 남겨요.)
- 화면 오른쪽 아래 톱니바퀴(⚙️) 버튼에서 **웹 화면 / 폰 화면** 고정과, 로그인 후 화면에 쓰일 **앱 색상**(네이비·그린·버건디·퍼플)을 고를 수 있어요. 두 설정 모두 그 기기·브라우저에만 저장돼요.
- 데이터(계정·활동기록·추천·작품)는 이제 브라우저가 아니라 **Firebase**라는 구글의 무료 클라우드 서버(Firestore)에 저장돼요. 그래서 같은 구글 계정으로 로그인하면 학교 컴퓨터든 집 PC든 폰이든 내 기록이 그대로 보여요.
- 파일 업로드 기능이 빠지면서 **Firebase Storage(그리고 결제 수단 등록이 필요한 Blaze 요금제)는 더 이상 필요 없어요.** Authentication과 Firestore만 있으면 돼요.

전체 과정은 20~30분 정도 걸려요. 이미 GitHub·Vercel·Gemini API 키까지는 설정해두셨다고 가정하고, **새로 필요한 Firebase 설정 위주**로 안내할게요.

## 1. Firebase 프로젝트 만들기 (무료, 카드 등록 불필요)

1. https://console.firebase.google.com 접속 후 구글 계정으로 로그인.
2. **프로젝트 추가** 클릭 → 프로젝트 이름 입력(예: `saengibu-coach`) → Google Analytics는 꺼도 괜찮아요 → **프로젝트 만들기**.
3. 프로젝트가 만들어지면 왼쪽 메뉴에서 **Authentication** 클릭 → **시작하기** → **Sign-in method** 탭 → **Google** 선택 → 사용 설정 켜고 프로젝트 지원 이메일 선택 → **저장**.
4. 왼쪽 메뉴 **Firestore Database** 클릭 → **데이터베이스 만들기** → 위치는 `asia-northeast3 (서울)` 추천 → **프로덕션 모드로 시작** 선택 → 만들기.

(이전 안내에 있던 **Storage** 설정 단계는 이제 필요 없어요. 이미 Storage를 만들고 Blaze로 업그레이드하셨다면 그대로 두어도 되고, 요금이 청구되진 않으니 걱정 안 하셔도 돼요 — 앱이 더 이상 Storage를 호출하지 않아요.)

## 2. 보안 규칙 설정하기 (중요 — 반드시 해주세요)

기본 상태로 두면 아무나 서로의 데이터를 읽고 쓸 수 있거나, 반대로 아무도 접근을 못 해요. 아래 규칙을 붙여넣어서 **본인 데이터만 본인이 접근**하도록 만들어야 해요.

**Firestore 규칙** (Firestore Database → 규칙 탭에서 아래 내용으로 전체 교체 후 게시):

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{uid} {
      allow read, write: if request.auth != null && request.auth.uid == uid;
      match /{document=**} {
        allow read, write: if request.auth != null && request.auth.uid == uid;
      }
    }
  }
}
```

## 3. 웹 앱 등록하고 설정값 가져오기

1. Firebase 콘솔 왼쪽 위 **⚙️ (프로젝트 설정)** 클릭 → **일반**(또는 **프로젝트 설정**).
2. 아래로 스크롤해서 **내 앱** 섹션 → **`</>`(웹)** 아이콘 클릭. (이미 앱을 등록해두셨다면 기존 값을 그대로 쓰면 돼요.)
3. 앱 닉네임 입력(예: `생기부 코치 웹`) → **Firebase Hosting 설정**은 체크하지 않아도 돼요 (Vercel을 쓸 거라서) → **앱 등록**.
4. 화면에 나오는 `firebaseConfig = { apiKey: "...", authDomain: "...", ... }` 값을 전체 복사해두세요.

## 4. index.html에 설정값 붙여넣기

`public/index.html` 파일을 열어서 `<script>` 태그 안, 맨 위쪽에 있는 이 부분을 찾으세요:

```js
var firebaseConfig = {
  apiKey: "여기에_Firebase_apiKey_붙여넣기",
  authDomain: "your-project-id.firebaseapp.com",
  projectId: "your-project-id",
  storageBucket: "your-project-id.appspot.com",
  messagingSenderId: "000000000000",
  appId: "1:000000000000:web:xxxxxxxxxxxxxxxxxxxxxx"
};
```

3단계에서 복사한 값으로 이 6개 항목을 전부 바꿔주세요. (이 값들은 비밀 키가 아니라 공개돼도 되는 설정값이에요 — Gemini API 키와는 다르게 보안 규칙이 실제 보호 역할을 해요. `storageBucket` 값은 이제 쓰이진 않지만 그대로 둬도 문제없어요.)

## 5. GitHub에 올리고 Vercel 재배포

수정한 `public/index.html` 파일을 GitHub 저장소의 같은 경로에 업로드(덮어쓰기)하면 Vercel이 자동으로 재배포해요. (이전에 안내한 것과 같은 방법 — **Add file → Upload files**)

## 6. 배포된 도메인을 구글 로그인에 허용하기 (중요 — 안 하면 로그인 안 됨)

1. Vercel에서 배포된 주소(예: `saengibu-coach.vercel.app`)를 복사하세요. `https://`나 `?` 뒤에 붙는 내용 없이 도메인만 있어야 해요.
2. Firebase 콘솔 → **Authentication → Settings → 승인된 도메인** 탭으로 이동.
3. **도메인 추가** 클릭 → Vercel 주소(`saengibu-coach.vercel.app`, `https://` 없이 도메인만)를 입력하고 추가.
4. 이 단계를 빼먹으면 로그인 버튼을 눌렀을 때 "이 주소는 아직 구글 로그인이 허용되지 않았어요" 오류가 떠요.

## 7. 확인해보기

1. 배포된 링크를 시크릿 창으로 열어보세요. 흰 배경의 앱 소개 화면(카드 2개) → "시작하기" → 구글 로그인 화면이 순서대로 나와야 해요.
2. 구글 계정으로 로그인하면 처음엔 "목표를 알려주세요" 화면이 떠요. 희망 대학교·학과를 입력하고 시작하세요.
3. 활동 기록을 하나 써보고 "AI 피드백 받기"까지 확인하세요.
4. **내 작품 페이지** 탭에서 제목과 글을 써서 저장해보고, 목록에 잘 보이는지 확인하세요.
5. 오른쪽 아래 ⚙️ 버튼에서 화면 모드와 색상을 바꿔보고 잘 반영되는지 확인하세요.
6. 로그아웃한 뒤 다른 브라우저(또는 시크릿 창)에서 같은 구글 계정으로 다시 로그인해서, 활동 기록과 작품이 그대로 보이는지 확인하세요 (기기를 바꿔도 데이터가 유지돼요).

## 화면 설정 (웹 화면 / 폰 화면 / 앱 색상)

화면 오른쪽 아래의 ⚙️ 버튼을 누르면 "자동 / 웹(컴퓨터) 화면으로 보기 / 폰 화면으로 보기"와 "앱 색상"(네이비·그린·버건디·퍼플)을 고를 수 있어요. 두 설정 모두 그 기기·브라우저에만 저장돼요(로그인 계정과는 무관). 앱 색상은 로그인 이후 화면에만 적용되고, 맨 처음 소개 화면은 항상 흰 배경으로 고정돼요.

## Firebase 무료 사용량 한도 (Spark 요금제)

Firebase는 신용카드 등록 없이 아래 한도까지 완전 무료예요. 학교 대회 규모라면 넉넉해요.

- Firestore: 저장 용량 1GiB, 하루 읽기 5만 회, 하루 쓰기 2만 회
- Authentication(구글 로그인): 별도 한도 없이 무료

한도를 넘으면 그날은 일시적으로 요청이 실패할 뿐, 자동으로 요금이 청구되지 않아요(Spark 요금제는 애초에 결제 수단을 등록하지 않는 요금제예요).

## 참고

- `api/feedback.js`, `api/recommend.js`는 이전과 동일하게 Google Gemini API를 호출하는 서버 코드예요. 이번 변경과는 무관하니 그대로 두면 돼요.
- `public/index.html`이 화면 전체(소개·로그인·목표설정·본문·작품 페이지)예요. 계정·활동기록·추천·작품은 이제 Firebase(Firestore)에 저장돼서, 로그인한 구글 계정을 기준으로 어떤 기기에서도 이어져요.
- 나중에 문구나 프롬프트를 수정하고 싶으면 해당 파일을 고친 뒤 GitHub에 다시 올리면 Vercel이 자동으로 재배포해요.
- 로그인이 안 되면 가장 먼저 6단계(승인된 도메인)를 확인하세요. 가장 흔한 실수예요.
